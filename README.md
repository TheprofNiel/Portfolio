# Niel Essien — Portfolio

Static one-page portfolio. No build step, no dependencies.

## Files

- `index.html` — the whole site (HTML + CSS + JS in one file)
- `images/` — portrait and project artifact images
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Deploy

Upload the contents of this folder to the repository root, then
Settings → Pages → Source: `main`, folder `/ (root)`.
